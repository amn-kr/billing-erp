Recovery key

This key opens the backups this computer makes (on a pen drive or in a folder). Keep this paper safe, away from the computer.

If this computer breaks or is lost:
  1. Install the app on the new computer and choose This PC only.
  2. Create an account and a shop (any name; it can be ignored afterwards).
  3. Settings › General › Backup & restore › Restore from files…: choose the pen drive or backup folder, type this key, then restore.

Anyone with this key and the pen drive can open the books. Without this key, the backups can’t be opened by anyone.
